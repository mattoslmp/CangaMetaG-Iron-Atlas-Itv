# Private collaborator review

The repository remains private. Grant access only to individual GitHub accounts:

```text
Repository
→ Settings
→ Collaborators
→ Add people
```

Do not share a GitHub password or a common account. A collaborator may review code, authorized figures and data, documentation, commits, pull requests and the locally executed application.

For future browser-based private review, create a private Streamlit app only after authorization, connect the private repository, grant access individually and avoid generating a public URL.
