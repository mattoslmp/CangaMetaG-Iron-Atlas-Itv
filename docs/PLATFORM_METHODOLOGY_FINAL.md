# Interactive platform methodology

The interactive platform was implemented as a modular Streamlit application in Python to provide reproducible access to the processed iron-metagenomic atlas, publication figures, supplementary tables, MAG summaries, KEGG/KEMET module matrices, curated KO-marker panels and antiSMASH biosynthetic-gene-cluster outputs. The application uses packaged CSV/XLSX data assets, a synchronized figure manifest and dedicated modules for supplementary-table loading, functional annotation browsing, integrated omics visualization, KEGG module completeness, antiSMASH report parsing and runtime dependency checks.

The platform serves the same corrected publication figures included in the manuscript and supplementary-material package. Visual outputs generated by the application that are not used as Main Figures 1-8 are stored in the supplementary material under `03_Supplementary_Figures/Application_Only_Figure_Archive/`, with a file-level manifest. antiSMASH outputs are parsed recursively from MAG/bin result folders, extracting available `index.html` paths, region-level product annotations and cluster summaries. MAGs without supplied or detected clusters are explicitly retained in the table as "no BGC clusters identified" so that the final matrix covers all expected MAG/bin identifiers.
