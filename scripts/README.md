# Canonical scripts

Only scripts documented in `tables/Supplementary_Table_16_final_scripts.*` are part of the active final workflow. `scripts/figures/generate_environmental_group_heatmaps.py` is the sole S40/S67 generator: it emits grouped-only S40 and both S67 layouts while reconstructing original-order S40 only for audit. `scripts/validation/compare_environmental_group_heatmaps.py` performs comparison only and never edits images. Figure-specific generators are isolated; shared code must not change non-target outputs. Preservation-only materialization is explicitly identified in Table 16 and never edits pixels or scientific values.
